4.1 O que é Ownership?

Ownership é a característica central da linguagem Rust. Embora seja simples de explicar, possui implicações profundas em todo o restante do design do sistema.

Todos os programas precisam gerenciar a maneira como utilizam a memória do computador enquanto estão em execução. Algumas linguagens possuem coleta de lixo (Garbage Collection); outras exigem alocação manual.

Em Rust, a memória é gerenciada através de um sistema de posse com um conjunto de regras que o compilador verifica em tempo de compilação sem nenhum custo adicional de runtime.

Distribuição Oficial

Instalação Simples & Sem Dependências

Escolha o seu canal preferido de instalação para Linux, macOS, Windows ou Docker.

# Instalar a CLI oficial em modo headless de alta performance

$ cargo install any2epub-rs


# Instalar com suporte à janela desktop nativa a 60 FPS (minifb)

$ cargo install any2epub-rs --features gui

# Baixar release v0.11.0 do GitHub com SHA256SUMS verificado

$ curl -LO https://github.com/Arkmedess/any2epub/releases/download/v0.11.0/any2epub-v0.11.0-x86_64-unknown-linux-gnu.tar.gz

$ tar -xzvf any2epub-v0.11.0-x86_64-unknown-linux-gnu.tar.gz

$ sudo mv any2epub /usr/local/bin/

# Executar conversor containerizado em ambiente rootless

$ docker build -t any2epub .

$ docker run --rm -v "$(pwd):/data" any2epub -i /data/livro.pdf -o /data/livro.epub
